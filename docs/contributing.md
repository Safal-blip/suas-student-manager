# Contributing

Thank you for your interest in contributing to SUAS Student Manager!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Follow [Getting Started](./getting-started.md) to set up your environment
4. Create a new branch for your feature: `git checkout -b feature/your-feature-name`

## Development Guidelines

### Code Style

- Follow TypeScript best practices
- Use strict type checking
- Maintain consistent formatting
- Use meaningful variable and function names

### Commit Messages

Use clear, descriptive commit messages:
```
type: description

Optional detailed explanation
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

### Pull Request Process

1. Update documentation as needed
2. Ensure all tests pass
3. Keep PRs focused and reasonably sized
4. Add descriptive PR title and description
5. Link related issues if applicable

## Testing

```bash
pnpm test
```

Ensure your changes include appropriate tests.

## Code Quality

```bash
pnpm lint
```

Fix any linting issues before submitting a PR.

## Questions?

Feel free to open an issue or start a discussion in the repository.
